Import and export information

Save files are parsed locally in your browser. Save character downloads a JSON backup. Imported values reflect the parser's current coverage; selected proficiencies, inventory attribution and active combat bonuses are not yet fully recovered.

Ordinary spell slots and pact magic have separate rows. Print / Save PDF opens the browser's print dialogue. Disable headers and footers there. Long sheets may need more than two pages; inventory is preserved rather than clipped.
